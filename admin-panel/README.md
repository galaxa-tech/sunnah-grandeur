# Sunnah Grandeur — Admin Panel

Admin dashboard for the Sunnah Grandeur Islamic lifestyle e-commerce store.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Runtime:** React 19

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install & Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
src/
  app/          # Next.js App Router pages
  components/   # Shared UI components
  lib/          # Utilities and helpers
```
